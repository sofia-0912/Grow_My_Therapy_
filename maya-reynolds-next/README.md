# Dr. Maya Reynolds, PsyD — Santa Monica Therapy Website

A Next.js 14 (App Router) + Tailwind CSS build of a psychologist's practice website.

The project has two parts, as required by the assignment:

1. **Clone** — the homepage reproduces the layout, structure, section order, typography and
   interaction patterns of <https://www.conejovalleycounseling.com/home>.
2. **Redesign** — the clone is reskinned with an original theme and every word of copy rewritten
   from Dr. Maya Reynolds's profile, plus one new section ("Our Office") that does not exist on the
   original site.

---

## Run it

```bash
cd maya-reynolds-next
npm install
npm run dev        # http://localhost:3000
```

Production check:

```bash
npm run build
npm start
```

Stack: Next.js 14.2.5, React 18.3.1, Tailwind CSS 3.4.10, `next/font/google`, `next/image`.
JavaScript (no TypeScript), no external UI library, no runtime dependencies beyond Next/React.

## Theme system

All colour and type decisions live in two places, so the whole site can be re-themed by editing
tokens rather than components.

`tailwind.config.js` — semantic palette:

| Token | Hex | Use |
| --- | --- | --- |
| `primary` | `#2E5747` | Deep pine — brand, quote band, footer accents |
| `primary-dark` | `#24463A` | Hover states |
| `primary-deep` | `#1C382E` | Headings, dark CTA band, menu overlay |
| `primary-light` | `#E7EFEA` | Text on dark surfaces |
| `primary-mist` | `#F3F7F4` | Tinted section backgrounds |
| `secondary` | `#F6F1E8` | Warm oat — alternating section bands |
| `secondary-dark` | `#EAE3D6` | Image frames on oat bands |
| `accent` | `#C0714F` | Clay — eyebrows, italic emphasis, rules |
| `accent-soft` | `#F3E4DC` | Accent on dark surfaces |
| `paper` / `ink` / `muted` / `line` | `#FCFAF6` / `#24312B` / `#5C6862` / `#E2DCD2` | Surfaces, body text, hairlines |

Typography (loaded with `next/font/google` in `app/layout.js`, exposed as `--font-serif` /
`--font-sans`):

- **Cormorant Infant** — headings, pull quotes, the italic accent word in the H1 (mirrors the
  original site's serif + italic-script pairing).
- **Mulish** — body copy, uppercase letterspaced eyebrows and text buttons.

Spacing and shape are standardised through component classes in `app/globals.css` and container
tokens in `tailwind.config.js`:

- `.section-pad` → `px-6 py-20 md:px-10 lg:py-28` on every section, so vertical rhythm is identical site-wide.
- `.eyebrow` → the small uppercase letterspaced label above headings.
- `.bleed-pad` → aligns full-bleed band text to the same left edge as the `max-w-wide` container
  (`calc(max(2vw, (100vw - 1800px) / 2) + 1.5rem/2.5rem)`), so hero/band text and boxed sections
  share one edge.
- Containers: `max-w-site: min(1480px, 92vw)` and `max-w-wide: min(1800px, 96vw)` keep content
  filling the page with small, consistent gutters at every width.
- `components/Reveal.js` → IntersectionObserver fade-and-rise on scroll for below-the-fold
  sections; respects `prefers-reduced-motion`.

Radii are deliberately tight (`rounded-sm`) and shadows minimal, matching the editorial feel of the
reference site rather than a card-heavy SaaS look.

## Clone → redesign mapping

| Original section (conejovalleycounseling.com/home) | Implementation on `/` |
| --- | --- |
| Header: wordmark + "Open Menu" | `components/Header.js` — sticky wordmark, inline desktop nav with Services dropdown, full-screen overlay nav below `lg` (Esc closes, scroll locks, closes on route change) |
| Hero: eyebrow, H1 with italic final word, subtext, underlined caps button, two images | Hero — eyebrow, H1 ending in italic *burnout*, subtext, `LinkButton`, portrait card aligned beside the text block |
| Hope band: H2, caps line, para, image, para | "You don't have to keep pushing through on your own." |
| "Who we help": H2 + three image cards | `WHO_I_HELP` — anxiety / trauma / burnout cards |
| Quote band | Full-width pine-over-photo quote band |
| "Our areas of expertise" + uppercase tag cloud + "…and more." | `EXPERTISE_TAGS` tag cloud, italic "…and more." |
| "How we work": eyebrow, H2, image, caps line, two paras, Learn More, second image | "A collaborative approach, paced to you." with offset image pair |
| Specialties: H2, H3, blocks with Learn More + side image | Three `SPECIALTIES` blocks deep-linking to `/services#…` |
| — | **New:** "Our Office" (Part 3 of the brief) |
| "Schedule an appointment": eyebrow, H2, paras, Book Now, image | "Find a therapist who is the right fit for you." |
| Footer: intro line, Navigate, Contact, Team, legal row | `components/Footer.js` — intro, Navigate, Contact, Practice, crisis line + legal row |

Button language is encapsulated in `components/LinkButton.js`: uppercase, letterspaced pill buttons
with an arrow that slides on hover, in `dark` / `light` / `primary` / `accent` variants.

Responsive behaviour: hero and bands are single-column under `md`, two-column from `md` up, with the
portrait rendered as a centered card — `object-contain` (whole photo) below `lg`, `object-cover` with
a face-aware crop inside an aspect-matched box above it. The header shows an inline desktop nav with
a Services dropdown from `lg`; below that a hamburger opens a full-screen overlay (Esc closes, scroll
locks, closes on route change). All imagery goes through `next/image` with accurate `sizes`.

## Copy and local SEO

Every line of copy is derived from the profile document — nothing is invented. Targets:

- **H1:** "A Santa Monica therapist for anxiety, trauma & burnout." — primary local keyword
  ("Santa Monica therapist") plus the three service keywords in the most weighted element.
- **Sub-headings** carry secondary keywords naturally: "Adults in Santa Monica and across
  California", "Therapy services for adults in Santa Monica", "A calm, private space in Santa
  Monica".
- **Body** mentions the city, state, neighbourhood reach and telehealth coverage without stuffing;
  methods (CBT, EMDR, mindfulness, body-oriented) are named as in the profile.
- **NAP consistency** — the same name, address (`45 W 123rd Street, Santa Monica, CA 90401`) and
  phone/email placeholder appear in the header overlay, Our Office, contact page and footer.
- **Structured data** (`components/JsonLd.js`): `Psychologist` with `areaServed`, `ItemList` of
  services on the homepage and `/services`, `Person` on `/about`, `FAQPage` on `/faqs` and
  `/contact`, `ContactPage` on `/contact`.
- **Metadata** in `app/layout.js`: `metadataBase`, title template, description, keywords, Open
  Graph, Twitter card, canonical URLs per page, `sitemap.xml` and `robots.txt`.
- **Accessibility:** skip link, semantic landmarks, one `h1` per page, logical heading order,
  descriptive alt text on every image, visible `:focus-visible` ring, `prefers-reduced-motion`
  respected, overlay menu uses `aria-modal` and `tabIndex` gating.

## Project structure

```
app/
  layout.js        fonts, metadata, viewport, skip link, Header/Footer
  globals.css      Tailwind layers + .eyebrow / .section-pad + a11y defaults
  page.js          homepage (clone + redesign + Our Office)
  services/ about/ faqs/ contact/ not-found.js sitemap.js robots.js
components/
  Header.js  Footer.js  LinkButton.js  CtaBand.js
  ServiceCard.js  ConsultForm.js  JsonLd.js  Reveal.js
lib/content.js     all copy and data in one place (services, FAQs, office, schema)
scripts/           extract-doc-images.mjs (pulls headshot + office photos from the profile Doc)
public/            images and favicon
```

Keeping copy in `lib/content.js` means an editor can change wording without touching layout, and the
same content feeds both the UI and the JSON-LD.
